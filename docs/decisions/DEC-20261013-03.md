bare basename keys (`safety-audit.ts`, …) while the correct `<variant>/`-prefixed
keys already existed — the project's first post-upgrade `verify-scripts` failed on

a project-content question.

the canary), and the defect was escalated to the root — fixed as upgrade-project
1.70.3 with the mechanics extracted to the unit-tested `helpers/registry-append.ts`
(PR #1530/#1535), then delivered back to this project through the #212 mirror sync.
