# DEC-20261013-02: Drift-Policy Override for Stale PLATFORM_HARNESS Mirrors

The 0.18.0 upgrade reported `skills/explain-me/references/PLATFORM_HARNESS.md` as
DRIFT (preserved) — same-version content differs, left untouched per ADR-0085 D3.
The project copies pre-dated the workspace model-literal cleanup and still carried
model-ID literals, tripping Check MM; the common template had restored the file with
literals-free content (the dangling SKILL.md/BUILD_GUIDE references fix, PR #1530/#1535).

The drift presumption (project customization) was examined and rejected for this
file: the content was orphan staleness, not an intentional local variant. All six
platform mirrors were deliberately overwritten from the restored template, and the
upgrade's DRIFT-preserve policy will keep the clean copies stable from here on.
